# Website media / صور وفيديوهات الموقع

اختار الفولدر المناسب ثم **Add file → Upload files**:

- [home](home/): الهوم والفيديو.
- [services](services/): صور الخدمات.
- [about](about/): الفريق والمؤسس.
- [projects](projects/): صور المشاريع.

يفضل WebP أو JPG للصور، بأسماء إنجليزية واضحة. ملفات المشروع الواحد تبقى داخل فولدر مستقل.
