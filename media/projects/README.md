# Portfolio / صور المشاريع

أنشئ فولدر لكل مشروع باستخدام اسم إنجليزي واضح. مثال:

```
project-name/
  cover.webp
  identity.webp
  packaging.webp
  signage.webp
```

ارفع غلافًا وصور تطبيقات حقيقية مع موافقة العميل على العرض. أرسل اسم المشروع والخدمات ودور PMP والتحدي والحل والتسليمات لتجهيز دراسة الحالة. لا تُنشر نتائج أو أرقام بلا إثبات وموافقة.

فولدر `kavra` مخصص لتجميع الملفات فقط؛ المشروع ما زال مسودة وغير منشور.
