# PMP website assets / ملفات الموقع

ارفع الملفات الأصلية المعتمدة داخل الفولدر المناسب باستخدام **Add file → Upload files → Commit changes** على نفس الفرع `preview/pmp-website`.

- `brand/`: اللوجو وأيقونة الموقع وصورة مشاركة الرابط.
- `media/home/`: فيديو الهوم وصورة الغلاف.
- `media/services/`: صور الخدمات الست.
- `media/about/`: صور المؤسس والفريق.
- `media/projects/`: صور المشاريع، فولدر منفصل لكل مشروع.

لا ترفع بيانات خاصة أو مستندات داخلية؛ الملفات تحت `public` قد تظهر للزوار عند نشر الموقع. ارفع فقط صورًا لديك إذن باستخدامها.

رفع الصورة لا يفعّل ظهورها تلقائيًا. بعد الرفع، حدّث سجل `content/assets.json` بالمسار والمقاسات والوصف واعتماد الاستخدام، واربطها بالمكون المناسب. نسخة GitHub Pages تحتاج إعادة بناء ونشر بعد توصيل الصور؛ ملفاتها مولّدة على فرع `gh-pages`، فلا ترفع الأصول هناك.
