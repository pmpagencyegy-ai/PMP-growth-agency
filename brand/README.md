# Logo and brand / اللوجو والهوية

ارفع النسخ الأصلية المعتمدة هنا:

- `pmp-logo.svg`: اللوجو، مع نسخة فاتحة وداكنة إذا توفرت.
- `favicon.svg` أو `favicon.ico`: أيقونة الموقع.
- `og-default.jpg`: صورة مشاركة الرابط، 1200 × 630 بكسل.

يفضل SVG للوجو وPNG بخلفية شفافة عند عدم توفره. لا تعيد رسم اللوجو من لقطة شاشة.
